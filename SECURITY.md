# Security Policy

## About this project
This is the official website of **Babyllon Studio (Celebration Studio)**, Bhiwandi, Maharashtra. It is a static website (HTML, CSS and JavaScript). It has no server, database, user accounts or payment processing.

## Supported versions
Only the latest version on the `main` branch is supported with security fixes.

| Version | Supported |
| ------- | --------- |
| Latest (`main`) | ✅ |
| Older commits | ❌ |

## Reporting a vulnerability
If you find a security issue, please report it privately. **Do not open a public GitHub issue.**

1. Use GitHub's **Security → Report a vulnerability** option on this repository, or
2. Message Babyllon Studio on WhatsApp at **7038723555** with the subject "Security Report".

Please include:
- A description of the issue and where you found it
- Steps to reproduce it
- Any screenshots or proof of concept

## What to expect
- We aim to acknowledge your report within **3 business days**.
- We will keep you updated while we investigate and fix the issue.
- Once it is fixed, we are happy to credit you if you wish.

## Scope
In scope:
- The website code in this repository
- Links, forms and scripts on the website

Out of scope:
- Third-party services (WhatsApp, Instagram, Google Maps, GitHub, hosting providers). Please report issues to those providers directly.
- Spam, social engineering or physical attacks
- Denial-of-service testing

## Privacy note
The contact form does not store data. It opens WhatsApp with a pre-filled message. Please do not send passwords or sensitive personal information through it.

## Responsible disclosure
Please give us reasonable time to fix an issue before sharing it publicly. Thank you for helping keep Babyllon Studio and its visitors safe.
